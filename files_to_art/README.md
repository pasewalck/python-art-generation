# Files 2 Art

Code to generate actual "bit maps" of a certain file or directory.

## How to use

Simply run the script `files_to_art.py`. On the first prompt enter directory or file path to generate art for. Next the app will prompt to choose a mode. Bit-Mode and Byte-Mode are the option, essentially this lets you decide between if a pixel represents a single bit or byte of information. Bit-Mode will generate a black and white image, while Byte-Mode will generate a multicolor image. An image will be generated.
